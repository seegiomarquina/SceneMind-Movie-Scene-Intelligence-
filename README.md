#  SceneMind  — Movie Scene Intelligence & Visual Similarity Detection

**Day 14 | Data Science & AI Portfolio Challenge**

SceneMind AI is a Computer Vision and Machine Learning project that analyzes video frames, extracts visual features using a pretrained deep learning model, and identifies visually similar scenes using cosine similarity.

The project transforms ordinary video footage into numerical visual representations, enabling automated scene comparison, similarity search, and visual clustering.

---

## Problem Statement

Movies and videos contain thousands of individual frames. Finding visually similar scenes, identifying recurring visual patterns, and organizing footage manually can be time-consuming.

SceneMind AI addresses this challenge by automating visual scene analysis.

The system extracts video frames, generates deep visual embeddings, compares scenes, and groups visually similar frames using machine learning techniques.

##  Project Objectives

- Automatically extract frames from video footage.
- Generate visual embeddings using pretrained ResNet50.
- Identify visually similar scenes using cosine similarity.
- Retrieve the Top 5 most similar scenes.
- Group scenes using K-Means clustering.
- Visualize scene relationships using Principal Component Analysis (PCA).
- Implement an efficient Top K selection algorithm using Python's Heap data structure.

##  Project Workflow

1. **Video Acquisition:** Download publicly available sample video footage.
2. **Frame Extraction:** Extract frames at fixed time intervals using OpenCV.
3. **Image Preprocessing:** Resize frames to 224 × 224 pixels.
4. **Feature Extraction:** Use pretrained ResNet50 to generate 2,048-dimensional visual embeddings.
5. **Similarity Search:** Calculate cosine similarity between frame embeddings.
6. **Top K Retrieval:** Retrieve the five most similar scenes using a heap-based selection method.
7. **Scene Clustering:** Apply K-Means to group visually similar frames.
8. **Dimensionality Reduction:** Apply PCA to visualize scene embeddings.
9. **Evaluation:** Examine clustering metrics and visual outputs.

##  Key Features

### 1. Automated Video Frame Extraction
Extracts representative frames from video footage using OpenCV.

### 2. Deep Visual Feature Extraction
Uses ImageNet-pretrained ResNet50 to convert images into numerical feature vectors.

### 3. Scene Similarity Search
Uses cosine similarity to identify visually similar frames.

### 4. Top 5 Scene Recommendations
Returns the five highest-ranking matching scenes for a selected query frame.

### 5. Intelligent Scene Clustering
Uses K-Means to organize frames into visual clusters.

### 6. PCA Visualization
Projects high-dimensional scene embeddings into two dimensions for visual exploration.

### 7. DSA Implementation
Implements Top K Similar Elements using Python's heap-based selection algorithm.

## 📊 Evaluation Metrics

The project uses:

- **Silhouette Score:** Evaluates cluster separation and cohesion.
- **PCA Explained Variance:** Measures the amount of embedding variance represented by the two-dimensional projection.
- **Cosine Similarity:** Measures similarity between visual feature vectors.
- **Top K Ranking:** Evaluates whether retrieved scenes are visually relevant upon inspection.

Actual numerical results are generated by executing the notebook.

##  DSA Problem Solved

**Problem: Top K Similar Elements**

Given a query scene and a collection of similarity scores, retrieve the K most similar scenes while excluding the query itself.

**Approach:** Python Heap / Priority Queue using `heapq.nlargest()`.

**Complexity:**
- Ranking time: O(N log K), after similarity scores are calculated.
- Auxiliary space: O(N) for the candidate list in this implementation.

##  Limitations

- The current implementation processes a limited number of frames from one video.
- Visual similarity does not necessarily indicate semantic or narrative similarity.
- ResNet50 is pretrained for image classification, not specifically movie-scene understanding.
- K-Means clusters do not automatically represent meaningful cinematic categories.
- The system does not identify movie titles, actors, characters, or plot information.
- The current implementation is a Colab-based prototype, not a production-scale video retrieval platform.
